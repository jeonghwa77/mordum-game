# 모르둠 익스트림 뇌사패턴 연습 (1~8인 온라인)

## 실행
1. Node.js(LTS)를 설치합니다: https://nodejs.org
2. 이 폴더의 **start.bat**를 더블클릭합니다. (또는 터미널에서 `node server.js`)
3. 브라우저가 열리면(http://localhost:3000) 닉네임을 넣고 **방 만들기** → 6자리 방 번호를 친구에게 알려주세요.

설치할 패키지는 없습니다. `server.js` + `public/index.html` 두 파일이 전부입니다.

## 친구가 접속하는 방법
- **같은 와이파이/공유기**: 서버 창에 뜨는 `http://192.168.x.x:3000` 주소로 접속.
  - 안 되면 **방화벽허용.bat**를 한 번 실행(관리자 "예") → 서버 재시작.
  - 그래도 안 되면: 상대 기기가 정말 같은 와이파이인지(휴대폰 데이터·게스트 와이파이 X), 주소 끝 `:3000`을 붙였는지, `https`가 아닌 `http`인지 확인.
  - 공유기의 'AP 격리/게스트 네트워크'가 켜져 있으면 기기끼리 통신이 막혀요. 이때는 아래 Cloudflare 터널을 쓰세요.
- **인터넷 너머 친구 (가장 쉬움)**: **외부공개.bat** 더블클릭
  1. 처음 한 번 Cloudflare 터널 프로그램(cloudflared.exe)을 자동으로 받아요.
  2. 게임 서버가 꺼져 있으면 같이 켜요.
  3. `https://xxxx.trycloudflare.com` 주소가 노란 글씨로 뜨고 클립보드에 복사돼요 → 친구에게 전달.
  - 그 창을 켜 둔 동안만 접속돼요. 켤 때마다 주소가 바뀌어요. 공유기 설정이나 방화벽 설정이 필요 없어요.
- **내 PC를 안 켜고 상시 운영 (고정 주소)**: Render 무료 웹서비스
  1. 이 폴더를 GitHub 저장소에 올림 (cloudflared.exe는 빼고)
  2. https://render.com → New → Web Service → 저장소 선택
  3. Runtime: Node / Build Command: 비워두기(또는 `echo ok`) / Start Command: `node server.js` / Instance: Free
  4. 발급된 `https://이름.onrender.com` 주소로 접속. 무료는 15분간 아무도 없으면 잠들고, 다음 접속 때 30초~1분 깨어나는 시간이 있어요.

## 조작
| 동작 | PC | 모바일 |
|---|---|---|
| 이동 | 우클릭 (누른 채 끌면 계속 따라감) | 탭(드래그) |
| 순간이동 | Space (마우스 방향, 쿨타임 5초) | 순간이동 버튼 (마지막 이동 방향) |
| 공격 | 좌클릭 | 공격 버튼 |
| 핑 (소리) | Ctrl + 클릭 / 휠 클릭 / G | 핑 버튼 → 탭 |

## 패턴 흐름 (타이밍)
1. 시작 시 각자 전하 랜덤 부여 (+ 파랑 / − 빨강, 인원 분배도 랜덤: 4/4, 0/8, 1/7 …)
2. **2초 후** 망치 장판: 맵 좌/우가 빨강·파랑으로 나뉨 → **2초 안에** 내 전하 색 구역으로. 이후 다른 색 구역에 있으면 즉사
3. 내 구역에서 보스 공격 (보스 체력 = 인원 × 1인당 공격 횟수, 광폭화 시간 넘기면 전멸)
4. 보스 체력 0 → 반구 장판 8개 등장 (빨강/파랑 랜덤, 최소 한 개씩은 다른 색). **3초간 망치 장판 유지**
5. 랜덤 1명에게 **변환 장판** (대상자를 따라다님) → 2초 뒤 사라질 때 그 위에 있던 사람 전하 반전 (대상자 본인 포함)
6. **3초 뒤 전지역 폭발**: 반구 장판 밖 / 다른 색 장판 / 한 장판에 2명 이상 → 사망. 생존자 승리

방장은 대기실에서 자리를 드래그&드롭(모바일은 두 칸 차례로 탭)으로 바꿀 수 있고, 결과 화면에서 "다시 하기"로 같은 자리 그대로 재시작합니다.

## 초수 · 보스 설정 (방장)
대기실의 **초수 · 보스 설정**에서 방장이 −/+ 로 바꿀 수 있어요. 다른 사람에게는 읽기 전용으로 보이고, 바뀐 값은 하늘색으로 표시돼요. "기본값" 버튼으로 되돌립니다.

| 항목 | 기본 | 범위 |
|---|---|---|
| 시작 → 망치 장판 | 2초 | 0.5~10 |
| 망치 장판 → 구역 판정 | 4초 | 0.5~10 |
| 보스 광폭화 (판정 시작 후) | 15초 | 5~120 |
| 보스 체력 0 → 변환 장판 (망치 유지) | 3초 | 0.5~10 |
| 변환 장판 유지 | 5초 | 0.5~10 |
| 변환 장판 소멸 → 전지역 폭발 | 7초 | 0.5~10 |
| 순간이동(Space) 쿨타임 | 5초 | 0~30 |
| 보스 체력 (1인당 공격 횟수) | 50타 | 5~300 |
| 변환 대상자 자리 뺏기 강제 | OFF | ON/OFF — ON이면 변환 대상자의 자리가 항상 지금 전하와 같은 색이라, 반전 후 반드시 다른 사람 장판으로 가야 함 |
| 자리 랜덤 | OFF | ON/OFF — 매 판 시작 시 방장 배치와 상관없이 8자리 중 무작위 배정 (대기실 배치는 그대로 유지) |
| 빈 자리 장판 비활성화 | ON | ON/OFF — 8명 미만일 때 주인 없는 자리 장판은 흐린 점선으로 표시되고, 그 위에 서도 '장판 밖'으로 판정 |

## 밸런스 조정
`server.js` 상단의 `C` 값(이동 속도, 각 단계 시간, 보스 체력, 장판 크기)을 바꾸면 됩니다.
순간이동 거리는 `public/index.html`의 `TP_DIST`입니다.
